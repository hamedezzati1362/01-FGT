## نکته‌ی طراحی (پیشنهاد بازنگری)
هر شعبه ۳۰ کاربر دارد و /27 دقیقاً ۳۰ Host می‌دهد؛ ولی Gateway هم یک آدرس مصرف می‌کند
(۳۰ کاربر + ۱ Gateway = ۳۱ نیاز). پس برای شعبه‌ها هیچ حاشیه‌ی رشد وجود ندارد.
