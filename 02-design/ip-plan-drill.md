| Block Size | 64 | 16 | 4 |
| Network | 192.168.50.0 | 192.168.50.64 | 192.168.50.80 |
| First Host | 192.168.50.1 | 192.168.50.65 | 192.168.50.81 |
| Last Host | 192.168.50.62 | 192.168.50.78 | 192.168.50.82 |

| Usable Hosts | 62 | 14 | 2 |
