## ۵) هنوز `Unverified` / نیازمند بررسی بیشتر
1. ترتیب دقیق Election در HA؛ رفتار `override`.
2. سینتکس دقیق: `vdom-link`، `local-in-policy`، `session-ttl`، `ssl-ssh-profile`، `sdwan service`، `execute ping-options`، `central-management`، `diagnose sys sdwan`، `diagnose npu`.
3. REST API Token و SNMPv3 روی FortiGate 7.0.3 (در این دور تأیید نشد).
4. وابستگی لایسنس VM برای FMG/FAZ، HA، VDOM و UTM.
5. جدول ASN، Tie-breakerهای انتهایی BGP، MRAI و Hash ECMP روی vIOS.
6. نقل از Fortinet Community (غیررسمی) برای ترتیب DNAT/Policy؛ با Debug واقعی تأیید شود.
7. خروجی‌های نمونه‌ی Debug/Session شبیه‌سازی آموزشی‌اند، نه خروجی واقعی.
